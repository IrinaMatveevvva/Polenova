# Random Task Generator (Генератор случайных задач)

**Автор:** Жабко Даниил Николаевич

## Описание проекта
Приложение с графическим интерфейсом на Python, предназначенное для генерации случайных задач. Пользователь может выбирать задачу случайным образом, фильтровать по типу (Учёба, Спорт, Работа) и добавлять собственные задачи в общий пул.

## Основные функции
* **Генерация случайных задач:** выбор задачи с учетом фильтрации.
* **Фильтрация:** по типам задач (Учёба, Спорт, Работа).
* **Добавление новых задач:** встроенная валидация, проверяющая, что поле не пустое.
* **История:** автоматическое сохранение всех сгенерированных задач в формате JSON.
